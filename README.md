a very basic paintings mod

## current features

### variants
paintings drop exact variant

### spawn in the world
you can find paintings in chests. and because of that you no longer can craft them.
if you're making a structure it's possible to spawn it on walls, but for now only the exact variant.

### trader
wandering trader will sell up to 3 variants at a time
you can trade the unwanted paintings for another variant (any painting you have instead of emeralds)

### rarity
paintings have different rarities. some are way harder to find

### backport
backporting paintings from later versions
